# Chain Rush

A hypercasual web game for Playgama.

**Draw a continuous line to connect moving candies of the same color.**
Chain 3+ candies = explosion + points. Reach the target score before the timer
runs out.

- 300 levels (parametric difficulty curve)
- 7 candy colors + golden, rainbow and bomb specials
- Coins, shop with illustrated boosters, rewarded & interstitial ads
- 100% downloaded assets (candy pack + Kenney UI/audio), no code-generated art
- Vanilla JS, responsive on every screen, no black bars

## Play

Open `index.html` (or serve the folder) — the game boots to the menu and
preloads all assets. The Playgama bridge and ads activate automatically when the
game runs inside the Playgama platform, and the game also runs standalone.

## Controls

- Touch / drag: draw a chain through same-color candies
- Tap the pause button (or press `P` / `Esc`): pause
